# 经典50层魔塔 · 个人学习与修改

手机和电脑访问：https://xdw-h.github.io/mota-50/

本项目保存H5魔塔广场提供的2026年经典50层复刻版，并提供本地启动和GitHub Pages自动发布。它不是QQ堂，也不是原始Flash程序的反编译成果。

## 游玩和开发

1. 在线点击“开始游戏”，选择纯净版或保留Flash特性的版本。
2. 游戏源代码位于`game/51/`，直接修改JavaScript即可。
3. 本机启动：`pwsh -NoProfile -File ./start.ps1`，浏览器访问`http://127.0.0.1:9510/`。
4. 地图、怪物、战斗和存档入口见[二次开发说明](二次开发说明.md)。
5. 修改完成后验证、用中文提交说明提交，再推送`main`；GitHub Actions自动更新在线页面。

存档保存在当前浏览器对应网站来源中，不自动跨手机、电脑或浏览器同步。清理浏览器数据可能丢失存档，请使用游戏内导出功能备份。GitHub Pages为静态服务，在线地图编辑器的文件保存接口和云端成绩服务不在本项目范围内。

## 回滚

对需要撤销的提交执行`git revert <提交号>`，验证后推送`main`即可重新发布。无需删除仓库或重写历史。
